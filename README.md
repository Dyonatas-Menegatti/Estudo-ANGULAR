Este repositório foi criado com o objetivo de aprofundar meus conhecimentos em desenvolvimento Front-End utilizando Angular.

## 🚀 Como Executar

Clone o repositório:

```bash
git clone https://github.com/Dyonatas-Menegatti/Estudo-ANGULAR.git
```

Acesse a pasta:

```bash
cd Estudo-ANGULAR
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
ng serve
```

Abra:

```bash
http://localhost:4200
```
