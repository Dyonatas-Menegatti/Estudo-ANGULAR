Bem-vindo ao Projeto Angular Guards

Esta aplicação foi criada para estudos de rotas, autenticação e proteção de páginas utilizando Guards no Angular.

Rotas Angular

Navegação entre páginas utilizando o sistema de rotas do Angular com organização moderna e componentização.

Guards

Controle de acesso às páginas privadas utilizando CanActivateFn para proteger rotas autenticadas.

Autenticação

Simulação de login utilizando localStorage para armazenar o token de autenticação do usuário.

Sobre o Projeto

O objetivo principal desta aplicação é praticar conceitos importantes do Angular como serviços, autenticação, Guards, roteamento e estrutura de componentes.

Todo o sistema foi desenvolvido apenas para fins de aprendizado, testes e evolução técnica em Angular.
