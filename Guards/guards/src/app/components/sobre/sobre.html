Sobre o Projeto

Aplicação desenvolvida para estudos de rotas, autenticação e Guards no Angular.

Objetivo da Aplicação

Esta aplicação foi criada com o objetivo de estudar e praticar conceitos fundamentais do Angular, incluindo roteamento, autenticação e proteção de páginas utilizando Guards.

Funcionalidades

  • Navegação entre páginas
  • Proteção de rotas com Guard
  • Simulação de login
  • Armazenamento de token no localStorage
  • Controle de acesso às páginas privadas

Tecnologias Utilizadas

O projeto foi desenvolvido utilizando Angular, TypeScript, HTML e CSS, seguindo uma estrutura simples para facilitar o aprendizado.

Finalidade

Esta aplicação não possui finalidade comercial ou de produção, sendo utilizada exclusivamente para estudos, testes e evolução técnica em Angular.
