## 📖 Sobre o Projeto

Aplicação desenvolvida em Angular para consulta e visualização de Pokémons utilizando a PokéAPI.

O projeto foi criado com o objetivo de aprofundar conhecimentos em Angular, aplicando conceitos fundamentais do desenvolvimento Front-End moderno, como componentização, Services, Pipes, consumo de APIs REST e manipulação de dados assíncronos.

---

## 🚀 Funcionalidades

- 🔍 Busca de Pokémons
- 📋 Listagem dinâmica de dados
- 🖼️ Exibição de imagens e informações dos Pokémons
- 🌐 Consumo de API REST
- 🔄 Atualização dinâmica da interface
- 📱 Layout responsivo
- ⚡ Tratamento de dados utilizando Services

## 🧠 Conceitos Praticados

### 🔧 Services

Utilização de Services para centralizar a comunicação com APIs e compartilhar dados entre componentes, seguindo o padrão de Injeção de Dependência (Dependency Injection) do Angular. :contentReference[oaicite:0]{index=0}

### 🔄 Pipes

Transformação e formatação de dados diretamente na interface, mantendo os componentes mais organizados e reutilizáveis.

### 🌐 Consumo de APIs

Integração com a PokéAPI através do HttpClient do Angular para obtenção de dados em tempo real. :contentReference[oaicite:1]{index=1}

### 🧩 Componentização

Separação da aplicação em componentes reutilizáveis para facilitar manutenção, escalabilidade e organização do código.

## ⚙️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/Dyonatas-Menegatti/Estudo-ANGULAR.git
```

Acesse a pasta do projeto:

```bash
cd Estudo-ANGULAR
```

Instale as dependências:

```bash
npm install
```

Execute a aplicação:

```bash
ng serve
```

Abra:

```bash
http://localhost:4200
```
